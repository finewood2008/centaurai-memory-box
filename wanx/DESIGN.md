# WANX UI 标准

万象采用 **WANX Material v1：米白纸感、陶瓷微浮雕、暖金属细节**。

后续客户端 UI 沿用这套标准，不另起蓝紫渐变或深色主视觉。保持中文优先、清晰的信息层级与真实可操作的控件。

主要操作使用暖深棕，次要操作采用浅色描边或轻量文字。每个一级页标题区最多两个操作控件。

完整规范、素材、使用边界与当前落地范围见 [UI 标准](docs/design/wanx-material-ui-standard.md)。已确认的视觉方向见 [材质参考图](docs/design/wanx-material-concept-v1.png)。

标准覆盖万象品牌；当前本机实现仅个人版。企业版及独立应用按后续任务单独落地，不能把设计标准文档当作已部署状态。
