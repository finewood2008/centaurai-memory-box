# 万象个人版记忆模型盒端接口交接

**状态：未完成**  
**负责：盒端开发团队实现并发布接口，客户端团队负责联调和验收。**

万象个人版的「设置 → 记忆模型」默认选择「使用万象盒端模型」。记忆摘要和技能进化分别选型，选型通过正式记忆推理接口生效。「使用本机模型配置」可恢复本机文本模型。向量检索继续使用现有嵌入模型，待盒端接口和索引兼容性验收后切换。

## 模型清单

记忆处理涉及前三项。对话、语音转录和图片生成在客户端为非必配项，均可选择「未设置」。一个模型可以承担多个通过验收的任务。

| 模型设置 | 能力标识 | 万象已有能力与对接要求 |
| --- | --- | --- |
| 记忆摘要 | `memory_summary` | 复用已启用的盒端文本模型。盒端提供此任务的默认模型和适用候选，并支持结构化摘要输出。 |
| 技能进化 | `memory_evolution` | 复用已启用的盒端文本模型。独立配置默认与候选，并验证长上下文和结构化技能输出。 |
| 向量检索 | `embedding` | 盒端源码已有知识库嵌入管理。请确认测试盒子实际可用的模型，并开放记忆的文档嵌入、查询嵌入和批量请求。 |
| 对话（非必配） | `agent` | 复用现有授权目录 `GET /api/providers/resolved` 的对话候选。确认已启用模型及盒端默认值，登记到能力清单并联调对话调用。 |
| 语音转录（非必配） | `asr` | 复用盒端已有语音模型配置和 `/api/voice/stt`。将已配置模型、默认值和可用状态映射到候选列表，核对模型引用与转录入口的对应关系。用合成音频验收。 |
| 图片生成（非必配） | `image_generation` | 复用盒端已有媒体生成配置。将已配置的图片生成模型、默认值和可用状态映射到候选列表，提供受保护的生成入口。验收从文本提示生成图片。 |

盒端团队需为六项分别登记默认模型、可选模型和可用状态，优先复用盒端已有配置。某项缺少可用模型时，请在盒端补齐并验收实际调用。记录盒子版本、模型真实 ID、支持的输入输出、调用入口和当前可用状态。客户端目录只呈现模型元数据。对话、语音转录和图片生成留空时，仍可运行记忆摘要、技能进化和向量检索。

### CentaurOS-79 实际盘点

现有授权文本目录返回 10 条供应商与模型组合。通用默认是 `admin-managed-deepseek/deepseek-flash`，可作为摘要选型。目录中同时有 `admin-managed-deepseek/deepseek-v4-pro`，可作为技能进化选型，仍需盒端验证结构化输出及实际调用。两个候选均为现有盒端配置。查询记忆模型专用目录返回 HTTP 404。嵌入、转写和出图的实际模型仍需盒端团队确认。

其他已列出的文本候选来自 `admin-managed-qeetoken`，包括 `deepseek-flash`、`deepseek-v4-flash`、`deepseek-v4-pro`、`gpt-6-astra`、`gpt-6-luna`、`gpt-6-sol`、`gpt-6.1-sol` 和 `gpt-6.1-terra`。

### 接口契约

**查询模型目录**的成功响应为 HTTP 200。顶层三个字段保留原有的默认文本模型信息。每项能力在 `capabilities` 中提供 `defaultRef` 和 `models`，模型引用采用 `provider_name/model`。无可用模型的能力返回空数组与 `null` 默认值。示例仅展示摘要和进化两项，正式响应应列全六项。

```json
{
  "model": "example-text-model",
  "name": "示例文本模型",
  "provider": "example",
  "capabilities": {
    "memory_summary": {
      "defaultRef": "example/example-text-model",
      "models": [{"provider_name": "example", "model": "example-text-model", "name": "摘要模型", "input": ["text"]}]
    },
    "memory_evolution": {
      "defaultRef": "example/example-reasoning-model",
      "models": [{"provider_name": "example", "model": "example-reasoning-model", "name": "技能进化模型", "input": ["text"]}]
    }
  }
}
```

**文本推理**使用 JSON 请求。`role` 可为 `memory_summary` 或 `memory_evolution`，`model_ref` 必须属于请求任务的可用模型。缺少这两个字段的旧客户端继续使用原默认模型。消息角色为 `system`、`user` 或 `assistant`，共 1 至 256 条纯文本消息。`max_tokens` 为 1 至 32768 的整数，盒端按模型输出限制收紧。`json_mode` 可选，默认为 `false`，开启时请求 JSON 对象输出。

```json
{
  "role": "memory_summary",
  "model_ref": "example/example-text-model",
  "messages": [{"role": "user", "content": "将以下虚构记录提炼为一句摘要。"}],
  "max_tokens": 512,
  "json_mode": false
}
```

成功响应为 HTTP 200。`text` 为非空字符串，`model` 为实际调用的模型 ID，`finishReason` 和 `usage` 在上游未提供时可返回 `null`。

```json
{
  "text": "示例摘要",
  "model": "example-text-model",
  "finishReason": "stop",
  "usage": {"input_tokens": 42, "output_tokens": 16}
}
```

| 情况 | HTTP | 响应中的 `detail` |
| --- | --- | --- |
| 缺少有效认证 | 401 | 沿用现有认证错误 |
| 会话无权访问 | 403 | `MEMORY_MODEL_FORBIDDEN` 或现有网关拒绝 |
| 当前默认模型未配置或不可用 | 409 | `MEMORY_MODEL_NOT_CONFIGURED` |
| 请求过大 | 413 | `MEMORY_MODEL_INPUT_TOO_LARGE` |
| 参数格式错误 | 422 | `MEMORY_MODEL_INVALID_INPUT` |
| 上游推理失败 | 502 | `MEMORY_MODEL_UPSTREAM_FAILED` |
| 上游推理超时 | 504 | `MEMORY_MODEL_TIMEOUT` |

旧盒端返回 404 或 405 时，客户端显示需要更新盒端。盒子断开时显示连接提示。「使用万象盒端模型」会等待可用的盒端模型，用户可主动切换到本机配置。
