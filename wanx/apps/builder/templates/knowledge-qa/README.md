# 好问 · 0.3.0

好问是一个配置模型、本地盒子知识库、文件空间与标准 Channel 的智能对话应用，同时是可在万象工坊继续改造的模板。

## 配置与使用

首页只保留会话与输入。进入“设置与通道”统一设置名称、回答风格、万象模型、星图知识库和文件空间。空间可选整个空间、目录或单个文件；应用会按当前目录成员读取，不把文件路径交给模型。尚未配置资料时可以进行通用问答。

开启资料处理前，管理员明确确认问题、有限历史及相关片段将发送给所选模型。模型可在万象中配置为本地或云端；知识库和原文件始终保存在当前盒子。检索文本限 UTF-8 TXT/MD/CSV/JSON，单文件256KB，每轮最多6个1200字符片段；其他格式可作为原件取用。

连接通道后，必须为每条通道配置可访问的资料子集、允许使用的人员/群、是否允许发送原文件，再启用好问服务。默认拒绝未配置的身份。群成员共享本群会话，不同群、私聊、通道、应用、账号与环境隔离。应用窗口关闭后，当前盒端服务仍可处理消息；盒子离线后停止。

- `/身份`：查看自己或当前群的平台ID，供管理员填写允许名单，不开放资料读取。
- 文字提问：检索授权来源并回答，分别展示资料依据与通用补充。
- `/出处 1`：按当前权限回查本会话最近答案的引用。
- `/文件`：列出当前通道获准发送的文件；`/文件 名称或编号`：发送唯一匹配的原件，最大20MB，仍受具体平台交付能力限制。

支持企微、飞书、钉钉和微信的既有标准适配器。首版通过可信宿主输入已有机器人连接参数；凭据只写入万象 Gateway，不进入模板源码、沙箱、对话或应用数据。实际连接状态及端到端交付需要真实通道验收，不能用单元测试代替。

## 授权和兼容

配置与选择授权在盒端按应用、账号、环境保存，不可由业务数据伪造；复制模板不继承配置、凭据或对话。每轮检查当前所有者、资料范围、Channel凭据版本和启用状态，模型生成后再次检查。移除、撤权或生成途中变更配置时，不交付旧片段或原文件。

启用了 local-data gate 的盒子暂不支持常驻通道委托。此时阻止创建/启用好问通道并明确提示，仍沿用当前用户的有限授权进行应用内问答；不回退使用传统身份或放宽团队规则。

旧口径、审核、人工处理、回归、评分与审计集合完整保留在高级功能，只有主动启用业务问答模式后使用。普通会话使用独立集合；历史来源原文仅能在当前权限检查后查看。原有已选择资料不自动扩为应用或通道共享授权，需管理员在设置中明确配置。

## 开发接口

保留 `api.data/model/files/knowledge`。新增最小的 `dialogue` 能力，传输为 `dialogue.invoke`，应用通过以下接口使用：

- `api.haowen.invoke('read')`：读取本环境配置、版本和通道状态。
- `api.haowen.invoke('save',{revision,name,style,sources:[{kind,id}],cloudAllowed})`。
- `api.haowen.invoke('ask',{conversationId,question,requestId})`：盒端统一问答和持久上下文，返回 content/supplement/evidence/notes/sourceScope；成功后重复请求不再调用模型。
- `api.haowen.invoke('evidence',evidence)`：实时来源回查。
- `api.haowen.invoke('channels.policy',{revision,id,enabled,subjects,groups,allowFiles,sources})`。
- `api.haowen.select('knowledge'|'space')`、`api.haowen.channels()`：可信宿主选择器；沙箱不能自行提交原始连接凭据。

模型选择仍复用应用主模型绑定。预览中的配置、授权和会话与生产分开，预览不能配置常驻Channel。源码与旧产物可通过工坊恢复；恢复版本不删除现有业务数据或服务配置。

源码：app.js为界面、settings.js为统一配置、conversation.js保存应用会话；advanced.js/repository.js/engine.js保留旧业务能力。盒端haowen.py与haowen_channels.py提供统一问答、范围检查和标准通道适配，无任意工具或Shell执行。
