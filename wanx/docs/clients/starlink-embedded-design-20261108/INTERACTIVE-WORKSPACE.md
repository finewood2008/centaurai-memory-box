## 当前可用体验

- 保留原有简化界面及右侧详情修正。图谱支持节点拖拽、关联节点动态调整、画布平移、滚轮缩放、适应画布与悬停关联突出；拖拽不误触证据点击。力学运算只改变显示坐标，不写知识数据。
- 资料区改为左侧按实际文件类型分组的列表、顶部多标签页、中心固定版本正文预览。列表搜索明确限定当前列表，继续保留原有分页。这里不是用户原文件系统目录，不制造文件夹层级。
- 资料可直接编辑解析正文，复用既有 correction API、来源片段 ID、基础版本检查和操作回执。保存完整片段集，生成新版本，原始文件与来源定位保留。未知结果重试复用原操作 ID 和完整请求，失败保留会话草稿。过大或不完整的正文拒绝局部覆盖；草稿不存浏览器本地持久存储。
- PDF、图片、表格和音频预览解析／识别／转写后的正文；本轮不提供原始版式渲染或二进制原件编辑。编辑会按本仓已确认配置重新处理，界面说明在线模型可能收到修改正文。
- WANX 内嵌版本标为“精简版”。完整版增加“精简版／完整版”切换，精简模式复用同一套 UI、万象账号、设备、数据仓及接口，不生成另一套知识副本。有未完成的正文编辑会阻止模式切换。
- WANX 打开完整版的入口仍仅在原有“更多 → 打开完整版”。完整版原有本体、推理、Skill 等页面保留。

## 代码与生成边界

WANX 唯一 UI 源在 `apps/builder/integration/team-client/data-view.js`、`data.css`、`starlink/{motion,materials,correction}.mjs`。资料校对通过 personal/team 数据服务及受限预加载动作复用现有私有认证路径，未新增公开 Key 权限、后台接口或 SDK 副本。两种客户端由 assembler 生成。

完整版使用当前固定来源 c08cb0fb060c06699349fcf50d3e57f68f33ba0e 的独立生产工作树 `.runtime/starlink-compact-producer`，没有从旧的本机后台桌面源码降级打包。生产源码差异保存在 [full-producer-changes.patch](full-producer-changes.patch)，可在该基线审查和恢复；构建脚本从 WANX 已生成的 renderer 复制共用 UI，不手工修改固定发布资源。现有高级 React workbench 构建保持原样。

原生适配额外处理了：部分动作的成功／失败封装；固定版本正文读取；省略结束位置时交由后台按实际正文长度及 65536 字符上限截断。仍校验仓、版本、请求白名单和迟到响应，不放宽任意 URL 访问。

本机候选完整版版本 `0.3.6-rc.20261108.compact.4`。来源清单明确标注 `sourceDirty: true`、`distributionClass: local-verification-only`，没有把未提交改动伪称为上游提交。
