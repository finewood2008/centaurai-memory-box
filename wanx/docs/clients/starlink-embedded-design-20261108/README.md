**导入即整理，图谱看结果，有疑问再确认。** 星图保留在万象客户端现有导航中；个人版与企业版使用同一套界面。用户不需要在简化版理解本体、抽取计划或发布版本。

本次是使用合成学院资料的交互设计预览。演示状态不表示真实文件已上传、模型已调用、知识已发布或接口已接通；不连接真实后端，不安装客户端，不改变原数据仓、权限或统一 Key。

## 页面结构

- 顶部展示当前数据仓、切换入口、设备与作用范围。主操作为“导入资料”。“打开完整版”保留在页首右侧原有“更多”菜单里，不在主界面、来源卡或授权摘要增加显眼入口。首次没有数据仓时，在导入流程内确认仓名，不进入规则配置向导。
- 只保留“知识图谱”和“资料”两个主要视图。图谱使用主区域，支持查找、类型筛选、节点聚焦、缩放和恢复全图；宽度不足时，详情进入抽屉，不挤压主图。
- 资料视图展示文件、来源、处理状态与最近整理时间；可查看原文、重试失败项。移除材料需要说明影响并确认。
- 整理状态和待确认数量分开表达，例如“已整理 · 3 项待确认”。点击数量定位相关资料或确认卡，不单独增加任务中心导航。
- 授权区只显示当前仓知识的使用状态与现有授权摘要。创建或撤销 Key、MCP 配置、模型设置、清空和删除仓等进入完整版。

首页说明：

> 把资料交给 AI，让知识自动相连。\
> 导入资料，星图自动整理其中的人物、主题与联系，每条知识都能回到来源。

## 核心交互

### 导入与自动整理

1. 选择“从电脑选择”或“从万象空间选择”，确认目标仓、文件范围和实际处理模型的位置。
2. 点击“导入并自动整理”，逐文件显示读取、整理和更新结果的进度。单文件失败不阻塞其他资料，重试只针对失败项。
3. 有原文依据、符合现有规则且无冲突的知识自动生效；其他候选保留待确认。完成后可查看“本次新增”的实体、关系与待确认项。
4. 系统不因资料进入简化版而新建外部授权或扩大 Key 权限。模型或权限不可用时给出明确提示，不静默切换模型或伪造完成状态。

演示中的导入与进度均为合成场景，不读取用户本机文件内容，也不发送资料。

### 来源与待确认

点击节点或关系，在侧栏展示类型、联系、原文摘录和材料定位。每张确认卡只处理一个问题，并说明选择影响。

- 同名不自动合并；确认同一身份需要可核验的来源依据。依据不足时补充资料、保留独立或转完整版。
- 讲师与学员按班级或场次记录角色，可以兼任，不能拆成互斥人员身份。
- 缺少签到不推断缺席，缺少结业依据不生成结业结论；否定参加不变成已参加。
- C21、C23 等资料条目编号不当作有效实体。无法按现有规则整理时说明问题并转完整版。
- 问题项不进入确定知识，不阻塞其他合格结果；跳过不会等同于确认通过。

### 轻量纠错

节点和关系提供“这条不准确”，用户可以补充简单说明。标记后暂停该条知识作为确定知识对外使用；涉及实体时同步暂停依赖关系，先显示影响范围。图谱保留问题标记与原文。

AI 根据来源生成修改前后对比，用户确认后才应用；缺少依据则继续待确认。撤销问题标记也是明确操作，恢复前须重新检查来源、版本和权限。标记、建议和确认必须有同一条可追溯记录，不能用一次前端状态切换代替后台治理。

### 打开完整版

高级操作统一从页首右侧原有“更多”菜单中的“打开完整版”进入，个人版与企业版保持同一位置；默认只保留一个完整版入口，菜单内另有刷新。携带当前账号范围、设备和数据仓；仅在完整版已支持时传递材料或问题定位。完整版重新验证权限并确认定位成功；返回后简化版刷新服务端状态，不复制另一套数据仓。

预览中此入口仅说明将打开的位置，不代表已启动真实完整版。企业版继续沿用现有管理员维护权限，不因两版共用 UI 扩权。

## 交互检查清单

以下是设计预览需要检查的场景，不是已通过的真实后端验收记录。

- [ ] 个人版与企业版显示正确的范围文案；企业版不新增维护权限。
- [ ] 切仓清除旧仓选择、来源和待确认卡；迟到的旧响应不能回填。
- [ ] 空仓、正常图谱、整理中、部分完成、失败和无可靠关系均有清楚呈现。
- [ ] 两种导入来源、多选、目标仓、逐文件进度与仅失败项重试可以理解。
- [ ] 点击节点或关系可查看合成原文；搜索和聚焦不改动底层知识。
- [ ] 同名、跨班角色、否定参加、缺签到、缺结业依据保持相应边界。
- [ ] 暂不处理不增加已确认数量；复杂问题可带上下文转完整版。
- [ ] 标记错误后显示暂停范围；修正有前后对比并需要确认；撤销标记不会静默改变事实。
- [ ] 授权摘要不显示 Key 明文，不提供生成或扩权按钮。
- [ ] 紧凑窗口下顶部操作可换行，资料不裁切，来源与确认抽屉可关闭，键盘可操作。

真实交付另需在独立测试仓验证图谱、检索、证据、脱敏和授权接口的一致性，并检查原有资料、人工修正与统一 Key 未受影响。设计预览通过不能替代该验收。
