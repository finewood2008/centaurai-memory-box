# 万象客户端升级说明 · 2026-10-27

## 提交范围

分支：`wanx1027`。以 CodeUp `master` 的 `c00ca91` 为基础，保留其设备身份、安全、网络预热和版本更新修复。本次不修改产品版本号，不发布安装包，不部署或重启服务。

个人版与团队版共用下述应用目录、安装和空间交互。开物仍只在团队管理员的工作区开放。

## 应用：云端目录与本地安装分开管理

- 两版统一为“万象应用／本地应用”；团队版原“公司应用”页签改为“本地应用”。
- 万象应用的目录、名称、描述、版本、下载和更新均通过现有云端商城接口获取，不再通过固定应用名单补充目录。
- 已成功读取的目录加密保存，并按账号及 Consumer 环境隔离。网络故障时可显示标记为离线的目录；认证、无效响应或完整性错误不得被缓存掩盖，离线不提供安装操作。
- 当前商城没有默认安装策略，客户端不再按固定名单自动安装。服务端以后补齐策略后另行接入。
- 按产品负责人批准，临时保留已有产品图标、海报、详情放大。图像索引仅提供图片；不添加应用、名称、版本或权限。云端 HTTPS 图标优先。
- 本地应用可通过系统选择器导入万象 ZIP 应用包，安装前再次确认，沿用包内容、平台、兼容和版本校验，不自动运行。renderer 不能直接指定任意本机路径。
- 新增安装来源记录仅用于界面分类，不参与授权。历史本机应用保留；不在云端目录中的火花等应用从本地应用管理。
- 本地管理支持打开、版本信息和卸载；有符合原规则的签名历史版本时可恢复上一版。业务数据不因卸载程序被删除。
- 团队版本地页另列当前盒子的内部上架应用，沿用盒端授权。管理员继续在开物验收、采用并管理上架，普通成员使用获准应用。

## 空间 MCP 与侧栏

- Agent 接入改为左侧列表、右侧详情；新建接入使用小弹窗。移除 Key 下拉和独立的记忆归档页，把导入提示词、记忆文件入口放入具体接入详情。
- 仅记录真实 Key 状态及调用时间；未调用的接入不显示“已连接”。保留单独的专属盘、额外授权及文件分享链接。
- 撤销操作的确认入口修正；已确认的撤销结果优先于旧的异步刷新。刷新失败时保留已撤销状态，授权撤销绑定正确的接入 ID。
- 空间侧栏压缩重复的成员与归属文字，将详细信息放到悬停说明，保留只读状态；隐藏空的常用位置，支持从侧栏隐藏专属盘。
- 配套私有管理响应增加 `canManageGrants`，说明额外授权是否由当前成员管理；不扩大权限，不改变公开 REST 或标准空间／星图 MCP。
- 共享集成源码与客户端生成脚本同步，避免重新打包覆盖空间界面。

## 窗口

个人版与团队版的主窗口在当前显示器工作区居中，默认上限 1100×760 逻辑像素，小屏最多占工作区宽高的 90%；保留缩放，最小尺寸不超过实际窗口。
