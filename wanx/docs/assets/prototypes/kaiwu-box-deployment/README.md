# 万象工坊部署交互原型（设计归档）

原型来自 `centuarai-wanx-app-dev-kit/prototypes/kaiwu-box-deployment/`（套件提交 `38628494284fab901c4059dfec0c0b0420353afc`），已归入万象保存设计依据。正式部署模块位于 `apps/builder/ui/deployment/`，接入进度见[实施计划](../../../plans/kaiwu-deployment-ui-integration.md)。

本目录仅为前端评审原型，不连接真实盒子，不实现后端，不保存凭据，不参与正式应用构建。页面刷新会重置模拟状态。

影响范围仅本目录；依赖 React、Vite 和 Phosphor 图标。上游构建、审批、回归只展示模拟摘要。
验收要求：提交后固定目标；同版本转正式；盒子及环境状态隔离；必需客户端离线不能成功；回滚保留业务数据；操作结果和回执同步独立。

## 本地运行

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

侧栏「演示场景」切换成功、客户端离线、预检阻塞、部分激活失败、回执待同步，也可重置演示。
关闭详情不停止页面内的演示进度；刷新页面会重置，不代表后端持久化能力。

```sh
npm run build
```

模板自带的 worker/ 与 Sites 构建文件只做静态托管适配，未启用、未部署，不含业务后端。
图标来自 [Phosphor Icons](https://github.com/phosphor-icons/react)，字体使用 PingFang SC / 系统无衬线字体。

## 演示数据约束

- v1.4.0 演示后端服务与客户端安装；v1.3.1 演示共享运行时加载。交付方式固定在发布版本中，转正式不改变发布包。
- 仅 v1.3.2 的两台盒子联调证明预置为通过，其他版本需在目标盒子完成联调才能正式发布。历史回滚使用已发布档案和单独的模拟兼容检查。
- 部分激活失败后的「恢复当前版本入口」补齐已提交版本，不隐式回退或恢复旧数据库。另建恢复记录，保留原操作失败结果。
- 操作结果、当前环境版本和回执状态分别展示。历史版本已被替换时不能打开应用。
- 全局只允许一个演示操作，简化原型操作；真实方案的并发控制仍按盒子和环境处理。
