# 部署前端归入 Builder

用户确认：正式部署前端以原万象 Builder（开物）为基础实现，个人工坊复用同一工作台；App Dev Kit 不维护另一套平台前端。

## 范围与依赖

- 平台实现位于 `apps/builder/ui/deployment/`，使用已有 `ui/api.ts` 受信请求通道及工作台模式切换。
- 既有后台提供能力、本人操作列表、详情、事件、回执、恢复查询与回执重投。生产 Adapter 仍不可用。
- 尚无项目已采纳版本到可信 release、target、审批／数据计划的查询。页面不能推导或伪造这些字段；本轮不开放发起部署、转正式或回滚提交，不扩展执行 Adapter。
- 仅迁移部署原型和平台设计资料；套件保留公共合同草案、离线校验器、样例和维护验收应用。合同 Schema 不在此轮重新定义。

## 验收标准

- 从原有项目进入部署，无新增独立登录、设备状态或产品壳。
- 真实不可用、请求失败、空记录和历史记录区分；没有模拟进度或前端生成成功回执。
- HTTP 202 不等于完成，回执重投 HTTP 200 不等于送达；以后台状态为准。
- 无完整可信部署输入时禁止提交；不将普通客户端安装宣称为双端部署。
- 后台操作、事件和回执只展示当前账号／项目对应内容；项目或会话变化后旧请求不得覆盖新状态。
- 原型保持明确的模拟标记且不打进正式应用；运行包不依赖 app-dev-kit 的原型目录。
- 已有合同校验工具与维护便签应用不受迁移影响。
