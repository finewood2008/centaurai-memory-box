# 万象 UI 标准 · WANX Material v1

确认日期：2026-11-04。

## 风格

以米白纸张为环境、浅色陶瓷为承载面、棕色为操作强调，暖金属用于少量结构细节。微浮雕与纸张纤维提供触感，正文仍保持干净可读。

参考：[用户已确认的六板块材质设计](wanx-material-concept-v1.png)。这是风格参考，不能截成整张 UI 图片代替真实按钮与文字。

## 组件

- 页头：同一高度、图标尺寸、中文/英文基线与说明位置；右侧少量主操作。图像装饰集中在页头右侧，不能影响命中区域、文本选择或滚动。
- 页头图标：统一使用米白陶瓷与香槟金浮雕 PNG。对话为双层气泡、应用为四格模块、工坊为应用面板与编辑笔、星图为关联节点、空间为分层资料夹、盒子为私有 AI 设备；使用相同光照、底座与尺寸，不叠加第二层容器。标准容器 72px，760px 以下窗口使用 60px，以补偿透明素材留白并与标题保持视觉平衡。
- 标题：主标题 25px、窄窗口 21px，系统中文无衬线。英文小字使用固定间距。常规正文 12–14px，详细材料与对话沿用原字号规则。
- 卡片：16px 圆角，米白陶瓷底、细暖灰边缘、顶部柔光和浅投影；不用厚重双层黑阴影。
- 按钮：9px 圆角、无外投影。主按钮为暖深棕实色配米白文字；次按钮为轻描边的浅陶瓷面，图标按钮默认透明。每处仅突出主要操作，危险动作仍用语义色和明确确认。保持原来的操作名称、禁用条件与确认流程。
- 输入：内凹感比卡片轻，边界与焦点清楚。不能用装饰纹理覆盖正在输入的文字。
- 侧栏：浅暖灰、紧凑列表；选中项采用浅砂色底和轻微金属边缘。
- 弹窗：沿用现有宽度、可关闭方式与滚动边界，统一纸感、边缘与阴影，不增加无用步骤。
- 动效：仅轻量 hover/focus 反馈，遵循 `prefers-reduced-motion`。不增加持续装饰动画。

## 素材与工程约定

- 样式唯一源：`apps/builder/integration/personal-client/material-theme.css`。
- 页头素材唯一源：`apps/builder/integration/personal-client/assets/material-v1/`。
- 六板块图标唯一源：`apps/builder/integration/personal-client/assets/section-icons-v2/`，目录内保存透明 PNG、生成提示词与素材哈希，个人版组装时一并复制。
- 素材来自内置 imagegen；提示词见 [生成记录](wanx-material-generation-prompts.md)，哈希见素材目录 `manifest.json`。
- `assemble-client.mjs personal` 将样式和素材复制到个人版。生成目录不是唯一来源，不能只修安装包而不保留可重新生成的源码。
- 页头图片只有背景，无任何业务文字、图标或按钮；名称、状态、计数、权限仍由原组件生成。
- 窄窗口仍使用原响应式列表/详情切换；降低装饰强度并让按钮换行，不能缩小可读文字来塞满一行。
- 不向外部请求图片、字体或脚本，断网仍能加载本地素材。

## 当前实现范围

当前落地个人版六个主模块、个人与设置、常用管理弹窗、便签、托盘/迷你对话，以及本地身份窗口的视觉外壳。企业版安装包本轮不更新。

不重写底层服务、账号与权限，不修改用户构建应用 iframe 内部的界面，不将终端输出、代码区和第三方网页强行改成浅色。更新过程中保留数据、草稿、历史版本和现有其他开发修改。

## 操作层级补充 · 2026-11-04

- 每个一级页图片标题区最多两个操作控件，一个常用主操作加一个次操作或更多菜单。
- 空间：标题区「上传／更多」；上传菜单区分文件与文件夹；更多收纳新建文件夹和分享链接。「空间 MCP」在“我的空间”所在的文件工具栏右侧直接展示。文件栏保留轻量导航、搜索、显示与排序；选中内容后显示下载和其他所选操作。
- 对话：标题区「更多／新对话」；历史显隐与通道配置收进更多。星图：「更多／新建数据仓」；打开独立星图和刷新收进更多。
- 应用的本地安装与刷新移至标题区，不在列表上方重复。工坊和盒子原有两项主操作保留。
- 菜单支持键盘、Esc 和点击外部关闭；原动作、权限、确认流程不变。危险操作保持文字提示和原确认步骤。
- 应用市场恢复大海报在上、简洁应用信息在下的 App Store 式推荐布局，不使用左右压缩的海报货架。目录和版本仍由云端决定。
- 工坊以页面预览为主体：版本信息改为一行、说明默认折叠、页签与预览版本选择共用工具栏，左侧项目独立滚动。窄窗口沿用列表/详情切换。
- 盒子页保留连接、状态与设备管理。终端和远程桌面收进「设置 → 盒子运维工具」，默认折叠；沿用原有连接、权限和 IPC，不增加 Dashboard 入口。
- 盒子页运行版本仅保留一行版本号或简短状态与「在设置中查看」。运行构建、报告时间、组件信息、升级过程及错误原因集中在「设置 → 版本与更新」；不把缺少版本证据显示为已核验。
- 主动切换板块后回到页首，避免上一页滚动位置遮住新页标题。对话在紧凑桌面宽度保持历史/正文双栏；更窄时使用原有可收起历史浮层，不能让正文被放在浮层下方的同一窄列中。

验证分别记录自动化、安装包一致性、原生客户端显示与真实业务结果。设计稿、素材生成成功或样式编译通过，都不能替代本机显示核验。
